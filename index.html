四、需要你手动完成的步骤

  • 装 Continue / Cline 插件：我无法代装 IDE 插件。请在你用的 IDE 里搜名字安装—— VS Code 扩展市场搜 Continue 或 Cline；JetBrains 在 Settings → Plugins 里搜。
  • 拉一个本地模型（Ollama 装好但还没模型）：
    > ollama pull qwen2.5:7b
    > ollama run qwen2.5:7b
    7B 模型约 4.7GB，首次拉取较慢；CPU 推理建议选 7B 以下的量化版（如 qwen2.5:3b）。
  • 重启一次终端：让新装的 Cursor / Ollama 进入 PATH（当前会话的 PATH 还没刷新）。

五、已知限制与处理记录

  • 无 NVIDIA 独显 → CUDA 不可用（torch.cuda.is_available() = False），已装 CPU 版 torch；vLLM 跳过。
  • Windows 长路径未开 → 导致首次装 llama-cpp-python 报 OSError。已把注册表 LongPathsEnabled 设为 1。
  • 本机无 C/C++ 编译器（CMake 找不到 nmake）→ 从源码编译会失败。已改用官方预编译 CPU wheel 源解决。
  • Ollama 安装包 1.5GB，且其托管在 GitHub Releases；直连 ollama.com 不通，最终走 SOCKS5 代理 curl 下载。
